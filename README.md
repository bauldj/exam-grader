# exam-grader — AI辅助纸质试卷阅卷技能包

> WorkBuddy Skill · v2.0 · 让 AI 像老师一样在试卷上批改，并且**越用越准**

对纸质试卷扫描件执行**分步引导**阅卷：材料清点 → 批量批改 → 交互裁决 → 成果展示 → 打包交付 → 复盘迭代。

核心原则：**AI初判 + 人工校核，教师是最终裁决者**；每步之间设检查点，经用户放行才进入下一步。

## 特性

- **仿真实教师批改**：在原扫描件上渲染手写体红笔 √/×/半对、大题小计、总分圈、红笔批语与卷尾行楷评语面板
- **答案优先比对**：有答案库时先读标准答案的数/式，与学生作答区定向逐字符比对，一致才判对（比开放识别准确得多）
- **7类典型失效 + 16条可落地规则**：全部来自真实批改实验中实际发生过的事故（切边丢题、跨栏漏看、确认偏误判对、官方答案错误、总分算错……）
- **学习与自进化（v2.0）**：阅卷结束自动生成复盘报告，提炼新误判类型与根因，经用户逐条批准后写入自身规则库——AI 提议，人批准
- **大班批量模式（v2.0）**：100–200人规模，模板一次复用、共性问题批量裁决、随机抽查5%、评语模板化、年级级统计

## 适用场景

| 场景 | 适用性 |
|---|---|
| 答题卡客观题（选择/填空/判断） | ✅ 最佳 |
| 计算/证明/推断/简答（数理化生英，需给分点 rubric） | ✅ 适用 |
| 文科论述题（政治/历史等） | ⚠️ 需先建要点库 |
| 语文/英语作文 | ❌ 不适用（无标准答案） |

## 安装（WorkBuddy）

1. 下载本仓库 `exam-grader/` 文件夹（Code → Download ZIP 解压，或 `git clone`）
2. 复制到个人技能目录：`C:\Users\<用户名>\.workbuddy\skills\exam-grader`
3. 重启 WorkBuddy 会话，对话中说"我要阅卷，按你的流程一步步引导我"即可触发

## 环境要求

- WorkBuddy（需具备视觉识别能力的多模态大模型）
- Python 3.10+，依赖 Pillow、numpy（`pip install pillow numpy`）
- 中文字体：华文行楷 / 微软雅黑（Windows 自带；其他系统修改脚本内字体路径）

## 仓库结构

```
exam-grader/
├── SKILL.md                        # 技能主流程（六步工作流）
├── references/
│   ├── accuracy-rules.md           # 精度经验：7类失效 + 16条规则（批改前必读）
│   ├── workflow-details.md         # 定位模板/数据格式/多页扫描/交互裁决
│   └── batch-mode.md               # 大班批量模式规范（50-200人）
└── scripts/
    ├── annotate_grading.py         # 渲染批改痕迹、脱敏、行楷评语面板
    ├── answer_key.py               # 答案库归一化比对判分（LaTeX↔普通写法）
    ├── calibrate_grid.py           # 扫描件叠加坐标网格，题位标定
    └── verify_marks.py             # 批改标记落点程序化验证
```

## 隐私与数据安全

- 全程本地运行，扫描件不离开本机（视觉识别由本机 WorkBuddy 所配大模型完成）
- 学生姓名脱敏为可选项，交付前主动询问
- 技能文件内的所有实证案例均已匿名化
