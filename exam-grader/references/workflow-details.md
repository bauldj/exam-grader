## 数据格式定义

### task.json

```json
{
  "task_name": "2026秋季限时训练4",
  "subject": "数学",
  "paper": "2026年广东中考基础题限时训练（4）",
  "total_score": 63,
  "sections": [
    {"name": "选择题", "count": 10, "per": 3},
    {"name": "填空题", "count": 5, "per": 3},
    {"name": "解答题", "count": 3, "per": 7, "rubric": true}
  ],
  "pages": 2,
  "created": "2026-10-12"
}
```

### roster.csv

```
姓名,班级,学号,文件夹
学生A,某班,001,stu01
```

### template.json（题位定位模板）

```json
{
  "paper": "限时训练4",
  "page_size": [1856, 4982],
  "rule": "坐标含绝对边界，禁止切边；双栏逐栏登记",
  "items": [
    {"no": 1,  "page": 1, "box": [560, 188, 760, 232],   "type": "choice"},
    {"no": 14, "page": 2, "box": [420, 1240, 760, 1330], "type": "frac"},
    {"no": 17, "page": 2, "box": [960, 2450, 1800, 2760], "type": "proof"}
  ]
}
```

- `type` 取值：choice（选择）/ fill（填空）/ frac（分数结果）/ work（解答过程）/ proof（证明）
- `type` 决定识别策略：frac 必须按分数线三层结构解析（accuracy-rules.md 规则4、5）
- **每页一个坐标体系**；page 字段必填

### answer_key.json

```json
{
  "paper": "限时训练4",
  "sections": [
    {"name": "选择题", "per_score": 3, "items": [
      {"no": 1, "answer": "A", "latex": "A"},
      {"no": 14, "answer": "5π/4", "latex": "\\frac{5\\pi}{4}", "normalized": "5pi/4"}
    ]},
    {"name": "解答题", "items": [
      {"no": 16, "score": 7, "answer": "-7/2",
       "rubric": [
         {"step": "(√3-2)⁰=1", "score": 2},
         {"step": "(1/3)⁻¹=3", "score": 2},
         {"step": "√3·cos30°=3/2", "score": 2},
         {"step": "结果-7/2", "score": 1}
       ]}
    ]}
  ]
}
```

### marks.json（批改标记，annotate_grading.py 的输入）

```json
{
  "paper": "scans/学生A/page.jpg",
  "mask": [[485, 18, 915, 100]],
  "marks": [
    {"no": 1,  "col": "L", "x": 855,  "y": 400,  "verdict": "ok",   "score": null},
    {"no": 6,  "col": "R", "x": 1795, "y": 390,  "verdict": "no",   "score": null, "note": "应为D"},
    {"no": 16, "col": "L", "x": 855,  "y": 4260, "verdict": "ok",   "score": "7分"},
    {"no": 18, "col": "R", "x": 1795, "y": 4050, "verdict": "part", "score": "1分", "note": "(2)(3)未作答"}
  ],
  "sections": [{"label": "24分", "x": 32, "y": 305}],
  "total": {"text": "54", "x": 1745, "y": 150},
  "comments": {
    "总评": "本次训练总分54分……",
    "items": ["正多边形计算——第6题……", "……"],
    "建议": "……"
  }
}
```

- `col`：L=左栏（标记落笔在栏右缘）、R=右栏
- `verdict`：ok（√）/ no（×）/ part（半对=√下加点）
- `mask`：姓名脱敏白矩形 [x1,y1,x2,y2]，可多块

## 题位定位模板建立流程

没有现成模板时，按以下步骤建立（约需2-3轮人机交互）：

1. **确认空白卷**：请用户提供与扫描件同版式、同分辨率的空白卷。分辨率不一致→提示重扫。
2. **生成网格标定图**：`python scripts/calibrate_grid.py --paper 空白卷.png --out grid.png --spacing 200`
   得到叠加坐标网格的图，读图获得每题的粗略 y 区间。
3. **双栏判定**：确认版式是否分栏。分栏卷必须逐栏登记（accuracy-rules.md 规则2）。
4. **逐题登记**：按网格读数填写 template.json，题型标注 type。
5. **细网格复核**：对可疑区域（长题、带图题、多小问题）用 `--spacing 50 --crop y1,y2` 生成局部细网格图复核。
   **长题溢出高发**：统计表、带图选择题、多小问解答题的实际占位远超估计。
6. **学生卷抽检**：抽1-2份学生卷，核对各题作答是否落在框内——学生卷与空白卷可能存在局部偏移。
7. **标记落点以学生实际落笔为准**：学生答案可能写在选项行、图旁、括号内，与印刷题干不同行。

## 多页扫描件处理

- 先问清：每生几页？扫描件是"逐页多文件"还是"多页拼成一张长图"？
- 逐页多文件：文件名含页码（如 `学生A_p1.jpg`），template.json 按页组织坐标。
- 长图拼合：确认拼接顺序与页边界 y 值，把页边界写进 task.json（`page_breaks: [y1, y2]`），
  各题坐标换算到长图坐标系。
- 页边界处最易发生切边丢题（accuracy-rules.md 失效1）——模板边界必须覆盖页首到页尾。
- 建议每生页数核对无误后再开始批改，避免批到一半发现缺页。

## 大模型选择提示

在阶段6开始前，明确提示用户：

> 阅卷识别手写内容需要**视觉多模态大模型**。请在 WorkBuddy 的模型选择中
> 选用具备图像理解能力的模型（如 Claude、GPT-4o、GLM-4V 等视觉版本）。
> 纯文本模型无法读取扫描件。
>
> 另外建议：识别与判分可以使用不同模型——识别用视觉模型，判分比对用
> 推理较强的模型，可降低"看错但算对"的复合误差。

## 不确定问题裁决流程

1. **先问用户偏好**：即时模式（逐题问）还是汇总模式（批完统一问）？
2. 不确定项的判定来源（出现任一即列入）：
   - 手写字形低置信（2/4、5/3 等易混字形）
   - 结构解析失败（根号、分数层读不出）
   - 空白与笔迹难分辨
   - 答案对但过程存疑（需 rubric 分步给分）
3. 呈现格式（每项）：**题号 + 裁图证据 + AI判读 + 候选答案 + 建议**
4. 教师裁决后：更新 marks/成绩 → 重渲染 → 请教师复核该题标记图
5. **全部裁决完成后，明确向教师确认："本轮判定双方均已确认，是否锁定成绩？"**
6. 将每条裁决记录写入 `疑难裁决记录.md`（题目、原判、改判、教师依据），
   并按 accuracy-rules.md 第七节沉淀为经验

## 脱敏操作

- 批改痕迹图生成**之后**必须询问：是否脱敏？全部还是指定学生？
- 手写签名的位置、大小因人而异（有人写很小，有人签名很大且下探到标题区），
  **必须逐卷用网格图确认签名边界**，不能用统一坐标。
- 白矩形覆盖即可（样卷展示的标准做法）。注意签名可能与页眉、标题重叠，
  覆盖时以"姓名不可辨认"为底线，允许残留与标题混叠的碎笔。
- 脱敏后用像素扫描验证：脱敏区内不应再有深色像素
  （但需排除印刷元素如校徽、"数学"字样、页眉）。

## 评语撰写规范

结构（参考真实批改报告样式）：

1. **总评段**：含总分（满分），整体完成度，失分集中区域
2. **数字序号要点**：每条 = 知识模块——具体错误（写清题号、学生答了什么、正确是什么、错因）
3. **建议行**：针对本次错误的可执行建议，避免空话

要点：
- 从科任老师角度写，语气专业、直接、对事不对人
- 错因要与卷面实际作答对应（如"cos30°误记为√3/3"而非笼统的"三角函数不熟"）
- 区分"知识缺漏"与"作答策略"（空白未答≠不会）
- 渲染到手写评语面板时：总评段 → 1. 2. 3. 要点 → 建议 行
